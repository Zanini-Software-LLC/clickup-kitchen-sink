# ClickUp Kitchen Sink (Unofficial Sample)

> **UNOFFICIAL SAMPLE.** This project is **not affiliated with, endorsed by, or sponsored by ClickUp** (Mango Technologies, Inc.). "ClickUp" is a trademark of its owner, used here only to describe API compatibility.

A kitchen-sink sample app that exercises as much of the public [ClickUp API v2](https://developer.clickup.com/) as possible: spaces, folders, lists, tasks, comments, custom fields, time tracking, webhooks, and goals.

## Data and AI policy

- **All data is synthetic.** No real user or customer data is created, read, or stored.
- **ClickUp AI is not used** to generate any content in this repository.
